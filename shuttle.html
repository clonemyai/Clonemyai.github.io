The shuttle

The shuttle moves a capsule file from one screen to another, directly. Open this page on both screens. The sending screen shows a six character code; type it on the receiving screen; the receiving screen accepts; the file crosses between the two browsers. No account, no upload, nothing stored on a server.

It is a Capsule Bridge transport: the same file the homepage makes, carried screen to screen instead of pasted by hand. The shuttle never opens the file. It cannot read it, parse it, or keep it.

What crosses where

Your file travels straight between the two browsers, encrypted in transit by WebRTC (DTLS), and it is never stored on any server. The introduction is borrowed for now: a public rendezvous service, the PeerJS broker, matches the code to the two browsers, and it can see the code, both IP addresses, and the time. It cannot see the file, and neither can we. A later version of the shuttle will run on clonemy's own rendezvous service; until then, that is the honest shape of it.

The code is a name, not a lock. What protects the file is that the receiving screen must accept a named offer before anything moves, and that the crossing itself is encrypted. Share a code only with the screen you mean to send to.
